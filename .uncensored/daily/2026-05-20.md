## Decisions
- CUDA feature disabled by default (requires explicit CUDA version feature for cudarc)
- Edition 2024 (supported by Rust 1.95.0)
- Workspace dependencies for shared crates, per-crate optional for cudarc
- profile-rustflags not stable yet — using .cargo/config.toml instead
- GGUF parser uses CursorReader over slice (no std::io dependency for parsing)
- SIMD matmul uses mul+add instead of FMA (bdver1 doesn't support FMA)
- Parallel matmul uses std::thread::scope with raw pointer slices for non-overlapping access
- CUDA backend uses cudarc crate for safe CUDA/cuBLAS bindings
- Inference engine uses direct tensor loading from GGUF (no computation graph yet)
- KV cache pre-allocated at context creation time
- GQA supported via head replication factor (n_head / n_head_kv)
- Server reloads model from file per request (TODO: Arc<Model> with shared weights)
- CLI supports interactive mode (stdin) and single prompt (-p)
- CI runs on push to master and pull requests
